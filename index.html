Sincronização com Google Sheets

Como configurar (5 minutos, uma vez só)
  1. Crie uma planilha nova em sheets.new.
  2. Menu Extensões → Apps Script. Apague o que estiver lá e cole o código abaixo.
  3. Clique em Implantar → Nova implantação → Tipo: App da Web. Em “Executar como” escolha Eu e em “Quem pode acessar” escolha Qualquer pessoa. Autorize quando pedir.
  4. Copie a URL do app da Web e cole no campo acima.
  5. Clique em “Sincronizar agora”. As abas Devedores e Pagamentos serão criadas, mais uma aba _backup usada para restaurar.
Se mudar o código depois, crie uma nova implantação para valer. Para usar senha, troque const TOKEN = '' no script e digite a mesma aqui.

Backup no computador

Seus dados ficam salvos no navegador (localStorage). Se limpar os dados do navegador eles somem — por isso exporte de vez em quando ou use o Google Sheets.
